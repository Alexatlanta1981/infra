> v1.0 is the **"get it working"** release. Every problem below was hit for real during deployment.

> All the 🔁 items are scheduled for **v1.2** (SSO / OIDC / IRSA, production-grade pipelines).

## 🔥 The two biggest lessons

1. **Most problems were authentication wiring** (#8, #9, #11, #16). Long-lived tokens and hand-typed IDs break easily.
   → v1.2 replaces them with SSO + OIDC + IRSA/Pod Identity (no stored secrets, no typos).
2. **"Applied successfully" ≠ "working".** Terraform said green, but the controller couldn't log in to AWS.
   → Always verify the running system (pods, ingress address, load balancer), not just the pipeline.
