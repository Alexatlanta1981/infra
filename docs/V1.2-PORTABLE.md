# v1.2 — Portable release

v1.2 lets anyone run the platform with their own AWS account, SSO and GitHub org. Nothing is tied to the original author.

## What changed from v1.1
- **No hardcoded org/account/bucket.** Set repo variables instead: `GH_ORG`, `TF_STATE_BUCKET`, `GH_REPO_SUBJECTS` (generate with `scripts/00_oidc_subjects.sh`), `SSO_ADMIN_ROLE_ARN`, plus the plan/apply role ARNs.
- **Terraform:** OIDC subjects are a required variable; the state bucket is passed with `-backend-config`.
- **Script 05:** reads the AWS account ID from your credentials (or `AWS_ACCOUNT_ID`) and injects it into the Argo CD apps.
- **gitops:** account ID and org are placeholders, filled in at deploy time.
- **CODEOWNERS:** placeholder; set your own handle or team.
- **Docs:** generic placeholders only; no account IDs, keys or secrets.

## How to run it
Follow [DEPLOY-RUNBOOK.md](DEPLOY-RUNBOOK.md), section "Using your own account/org". All changes go through pull requests and CI.
